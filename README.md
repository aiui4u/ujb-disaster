# 의정부시 재난상황판

현재 디자인을 유지한 GitHub Pages용 화면입니다. 날씨는 의정부시청 대표 날씨만 제공합니다.

## 데이터
게시용 JSON은 web/data.json 단 하나입니다. 재난자료, 특보, 시청 대표 날씨를 함께 저장합니다. 동별 날씨와 지역 선택 기능은 제거했습니다.

## 이번 단계
화면 업로드용입니다. 수집기와 자동 배포는 다음 단계에서 연결합니다. 초기 자료는 첫 수신 대기 상태이며 실제 관측값을 꾸며 넣지 않았습니다.

web 폴더를 게시합니다. src는 화면 원본이며 Node.js 22.13 이상에서 npm install 후 npm run build로 다시 빌드할 수 있습니다. 빌드는 web/data.json을 유지합니다. API 키와 서비스 토큰을 공개 파일에 넣지 마세요. 기존 Sites 사이트는 변경하지 않았습니다.
